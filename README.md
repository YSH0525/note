## 폴드노트 앱 (`app/`)

갤럭시 Z 폴드8에 맞춘 노트·다이어리 웹앱(PWA).

- **커버 화면**: 한 장씩 보는 화면 + 하단 탭
- **메인 화면(펼침)**: 수첩 펼침면처럼 목록/달력 + 편집면 두 쪽 레이아웃
- 노트: 작성·검색·고정, 자동 저장, 체크리스트(박스 탭으로 완료 전환), 휴지통(30일 보관)
- 다이어리: 달력 + 기분·날씨·활동 이모지, 월간 기분 분포·연속 기록 스트릭, 지난 오늘(과거 기록 다시 보기)
- 라이트/다크 테마, PIN 잠금, JSON 백업·복원, 오프라인 동작

실행: `app/index.html`을 브라우저로 열면 된다(서버 불필요). 주소 뒤에 `#demo`를 붙이면 샘플 데이터가 채워진다.
