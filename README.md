## 폴드노트 앱 (`app/`)

갤럭시 Z 폴드8에 맞춘 노트·다이어리 웹앱(PWA). 만든 곳: **Yoonque Labs**. 무료로 배포한다.

- **커버 화면**: 한 장씩 보는 화면 + 하단 탭
- **메인 화면(펼침)**: 수첩 펼침면처럼 목록/달력 + 편집면 두 쪽 레이아웃
- 실행하면 오늘의 다이어리부터 열린다 (앱 아이콘 길게 눌러 '새 노트'로 바로 시작 가능)
- 노트: 작성·검색·고정, 자동 저장, 체크리스트(박스 탭으로 완료 전환), 휴지통(30일 보관), 사진 첨부, 폴더 분류
- 다이어리: 달력 + 기분·날씨·활동 이모지, 월간 기분 분포·연속 기록 스트릭, 연간 기분 히트맵, 일기 템플릿, 지난 오늘(과거 기록 다시 보기), 사진 첨부
- 플렉스 모드: 반 접으면(노트북 자세) 위=보기 / 아래=쓰기 자동 분할
- 저장소: IndexedDB(기존 localStorage 데이터 자동 이전), 사진은 리사이즈 후 저장
- 라이트/다크 테마, PIN 잠금, JSON 백업·복원, 오프라인 동작, 홈 화면 바로가기(새 노트·오늘 일기)

실행: `app/index.html`을 브라우저로 열면 된다(서버 불필요). 주소 뒤에 `#demo`를 붙이면 샘플 데이터가 채워진다.

### 배포

`main` 브랜치에 푸시하면 GitHub Actions가 `app/` 디렉터리를 GitHub Pages로 자동 배포한다.

- 배포 주소: **https://ysh0525.github.io/note/**
- 폴드8 브라우저에서 이 주소를 열고 **"홈 화면에 추가"** 하면 일반 앱처럼 설치된다(오프라인·앱 바로가기 지원)
